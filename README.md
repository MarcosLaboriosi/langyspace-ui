# @langyspace/ui

Biblioteca React compartilhada pelos produtos Langy.space.

O primeiro release terá apenas um `Button` pequeno e explícito. O pacote será publicado como um
artefato versionado de GitHub Release e consumido por URL imutável.

## Development

Requirements: Node 24 and pnpm 10.33.2.

```bash
pnpm install --frozen-lockfile
pnpm run lint
pnpm test
pnpm run build
```

O contrato público, instalação e release serão documentados com a implementação do Button v1.
