# T08 — Revisão financeira e handoff

## Objetivo

Decidir a próxima onda com evidência dos pilotos, sem ampliar automaticamente o V1.

## Trabalho

- medir redução de source, defects e esforço de implementação;
- revisar cobranças, assinaturas, repasses, despesas, influencers e planos contra a API publicada;
- identificar o que cabe sem alteração pública;
- criar proposal separado para bulk selection se cobranças exigir;
- classificar agenda/marketing como migrar, pattern diferente ou manter local;
- atualizar discovery/progress/release evidence e abrir tasks da próxima onda.

## Aceite

- cada uma das 16 tabelas e duas listas possui decisão atualizada;
- nenhuma capability hipotética entra no package;
- limitações e regressões dos pilotos estão registradas;
- próxima task possui escopo pequeno, dependências e visual states;
- handoff distingue publicado, adotado, produção comprovada e trabalho aberto.

## Veredito visual final

Registrar exatamente um dos vereditos exigidos pelos repositórios, com rotas, estados, larguras e
screenshots que sustentem a conclusão.
